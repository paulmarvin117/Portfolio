About me

I'm a software developer who spends most of my time on the backend, the part of an app that users never see but always feel. I care about code that is easy to read, easy to test and easy to hand to someone else.

Python is where I go when I want to move fast. C# and .NET are where I go when I want structure and strong types. I enjoy using both, and I like picking the one that fits the job.

Azure is my favourite place to run things. I like how quickly an idea can go from my laptop to something live that people can use.
